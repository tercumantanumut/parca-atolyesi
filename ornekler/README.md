# Örnek görseller

Kendi görsellerin yoksa denemek için üç örnek:

| Dosya | Ne | İyi gider |
|---|---|---|
| `maceraci.png` | A-pozunda maceracı karakter (pelerin, kalkan) | Parçalı rota: pelerin, kalkan, kılıç ayrı parça olur |
| `tas_golem.png` | Sevimli yosunlu taş golem | Hafif rota, tek görselden yaratık |
| `hazine_sandigi.png` | Hazine sandığı (prop) | Hafif rota; 3/4 açıdan çizilmiş eşya |

Görseller bu depo için yapay zekâ (Gemini) ile üretildi; özgürce kullanabilirsin.
